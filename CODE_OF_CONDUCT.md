# Code of conduct

Mojara is an open-source project for developers of different backgrounds and experience levels. We expect contributors and maintainers to communicate respectfully and professionally.

Welcome constructive criticism of code, tests, documentation and technical decisions. Do not engage in harassment, personal attacks, discrimination, threats, doxxing, spam, or publication of private information.

Disagreements should focus on evidence, reproduction steps and the technical problem. Maintainers may edit or remove inappropriate contributions, close disruptive discussions, or restrict repeat offenders.

Report a conduct problem to the repository maintainers using a suitable private communication channel. Do not include personal or sensitive details in a public issue.
