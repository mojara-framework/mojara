# Security policy

## Supported releases

| Version | Security maintenance |
| --- | --- |
| 1.2.5 (Linux x86-64) | Current stable release |
| Linux ARM64 / macOS previews | Experimental, no production support |
| Native Windows | Not released |

## Reporting vulnerabilities privately

Please **do not post sensitive exploit details, credentials, or unpublished vulnerabilities in a public issue**. Use GitHub's private **Report a vulnerability** option under this repository's **Security** tab when available. If private vulnerability reporting is not enabled, contact the repository maintainers through an appropriate private channel rather than publishing exploit details.

Include a minimal reproduction, affected version/OS, security impact and suggested fix if known. Do not disclose other users' data or attempt to compromise third-party systems.

Maintainers will investigate and coordinate a fix and release notes before public disclosure. No response-time or remediation-time guarantee is promised here.
