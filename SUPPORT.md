# Support

For installation, how-to guides and CLI reference, start at [mojara.kasua.ng/docs](https://mojara.kasua.ng/docs/).

For a reproducible bug in the framework or CLI, [open an issue](https://github.com/mojara-framework/mojara/issues/new/choose). Include your Mojara version, Mojo version, OS/CPU, reproduction and logs with credentials removed.

For enhancement ideas, use the feature-request template.

For security concerns, use the private route described in [SECURITY.md](SECURITY.md); do not file a public security report.

## Supported development environments

Linux x86-64 is currently the fully supported Mojara v1.2.5 target. Windows developers use Ubuntu on WSL2. ARM64 and macOS are being validated; check [platform status](docs/CROSS-PLATFORM.md).
