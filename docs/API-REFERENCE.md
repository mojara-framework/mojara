# Mojara API reference

The public Mojo API is documented by module. Use the signatures and examples below as the first-party reference for writing Mojara applications.

- [Application, API, authentication, configuration, forms, lifecycle, logging and database foundations](api/FOUNDATIONS.md)
- [SQL integrations, pools, runtime, schemas, security, telemetry and web utilities](api/INTEGRATIONS.md)

The entries follow the `source/mojara/` implementation and exclude private underscore-prefixed functions and types. The framework's public responses and handlers are documented under Mojara module names; internal third-party packages are not a separate Mojara API.
