# File uploads

Mojara accepts browser forms, single files and multiple files. Use `parse_form(req)` when text fields and files are submitted together. Use `UploadFile` or `UploadFiles` for dedicated, authenticated upload endpoints that store files using generated names.

All three examples use the public `mojara` API. No Flare imports or separate multipart parser are needed.

## 1. Upload one file

Create `app.mojo`:

```mojo
from mojara import App
from mojara.web import UploadFile
from std.os import getenv


def main() raises:
    var app = App()
    app.post_handler(
        "/upload/photo",
        UploadFile(
            "private_uploads",
            max_bytes=2 * 1024 * 1024,
            required_token=getenv("MOJARA_UPLOAD_TOKEN", ""),
        ),
    )
    app.run_configured()
```

Create a private upload directory, configure your server-side upload token and start the application:

```bash
mkdir -m 700 -p private_uploads
export MOJARA_UPLOAD_TOKEN="replace-this-with-a-random-secret-of-at-least-24-characters"
mojara dev
```

Send one photo:

```bash
curl -i http://127.0.0.1:8000/upload/photo \
  -H "X-Mojara-Upload-Token: $MOJARA_UPLOAD_TOKEN" \
  -F "photo=@./portrait.png;type=image/png"
```

The endpoint returns HTTP **201** with `stored_name` and `bytes`. The saved filename is generated by the server; uploaded filenames are never used as storage paths. `UploadFile` checks the upload token and file-size limit. The upload directory must be private and writable by the application.

## 2. Upload multiple files in one request

Use `UploadFiles` when several attachments must be uploaded and stored together:

```mojo
from mojara import App
from mojara.web import UploadFiles
from std.os import getenv


def main() raises:
    var app = App()
    app.post_handler(
        "/upload/attachments",
        UploadFiles(
            "private_uploads",
            max_file_bytes=2 * 1024 * 1024,
            max_total_bytes=6 * 1024 * 1024,
            max_files=3,
            required_token=getenv("MOJARA_UPLOAD_TOKEN", ""),
            allowed_mime_types="application/pdf,image/png",
        ),
    )
    app.run_configured()
```

With the same private directory and upload token configured, send two attachments:

```bash
curl -i http://127.0.0.1:8000/upload/attachments \
  -H "X-Mojara-Upload-Token: $MOJARA_UPLOAD_TOKEN" \
  -F "files=@./application.pdf;type=application/pdf" \
  -F "files=@./passport.png;type=image/png"
```

The endpoint returns HTTP **201** and a JSON object with `count` and `files` (generated names, sizes and declared MIME types). `UploadFiles` validates the collection before saving and rolls back created files if the upload fails. Its MIME allowlist checks the submitted media type, not the actual file contents.

## 3. Submit text fields and files in the same form

A user registration or profile form often includes a name, description and optional picture. In a regular Mojo route, `parse_form(req)` reads all of them in one call:

```mojo
from mojara import App, Request, Response
from mojara.forms import parse_form


def create_profile(req: Request) raises -> Response:
    var form = parse_form(req)
    var username = form.get_first("username")
    if not Bool(username) or username.value().byte_length() == 0:
        return Response.error(400, "Username is required")

    var avatar = form.file("avatar")
    if Bool(avatar):
        var picture = avatar.value().copy()
        if picture.size() > 2 * 1024 * 1024:
            return Response.error(413, "Image is too large")
        if picture.content_type != "image/png":
            return Response.error(415, "Choose a PNG image")
        return Response.text(
            "Received " + username.value() + " with "
            + String(picture.size()) + " image bytes"
        )

    return Response.text("Received " + username.value() + " without an image")


def main() raises:
    var app = App()
    app.post("/profile", create_profile)
    app.run_configured()
```

This HTML form works with that route:

```html
<form action="/profile" method="post" enctype="multipart/form-data">
  <label>Username <input name="username" required></label>
  <label>Profile picture <input type="file" name="avatar" accept="image/png"></label>
  <button type="submit">Save profile</button>
</form>
```

The example reads the upload in memory and returns its size; it does not store the picture. For multiple files within the same mixed form, use `form.files("attachments")`, which returns every file with that field name in submission order. Binary bytes are available through `file.body` and are not converted to text.

## Choosing an upload API

| Requirement | Mojara API |
| --- | --- |
| Ordinary text form | `parse_form(req)` |
| Mixed text fields and uploaded files | `parse_form(req)`, `form.file(...)`, `form.files(...)` |
| Automatically store one uploaded file | `UploadFile` |
| Automatically store several files together | `UploadFiles` |

Authentication and authorization are application responsibilities. The dedicated upload handlers require an upload token; mixed form routes should require the same session and CSRF protections as other state-changing routes. When accepting images or documents, validate the actual bytes as well as the declared MIME type before treating the file as trusted.
